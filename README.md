# DART-SCORER

A full-stack, monorepo-based Dart Scoring application built for fast, reliable, and real-time match tracking. Designed with a modern frontend and a high-performance backend.

---

## 🛠️ Tech Stack

* **Workspace & Package Management:** [pnpm Workspaces](https://pnpm.io/workspaces)
* **Frontend:** [Vite](https://vitejs.dev/) + [React](https://react.dev/) / [TypeScript](https://www.typescriptlang.org/)
* **Backend:** Node.js / TypeScript
* **Code Quality & Tooling:** [ESLint](https://eslint.org/), [TypeScript Compiler](https://www.typescriptlang.org/)

---
